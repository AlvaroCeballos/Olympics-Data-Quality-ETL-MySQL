## PROYECTO FASE 3

Se les ha solicitado cargar la información relacionada a las olimpiadas en la Fase 1 que debe incluir toda la información de las fuentes y correcciones encontradas.

El alcance de la data será definido en clase, en reuniones conforme el avance del proyecto.

Para esto deben entregar:

- a) Utilizar los datos de su fase uno y cargar los mismos a una base de datos NoSQL (Mongo DB). Deben estar completos, si algo fallo en la carga a la base de datos relacionar aquí debe estar corregido.

- b) Entregar todos los scripts utilizados para la creación de los documentos y colecciones, índices, incluyendo los scripts para carga de datos con sus archivos fuente. Documentación con fecha y hora de ejecución.

- c) Realizar un método/script que reciba como primer parámetro el nombre del atleta y que despliegue toda la información relacionada con el mismo, participaciones, resultados, medallas, el formato de salida es a su criterio. Pueden agregar parámetros para mostrar o filtrar información específica, por ejemplo, deporte, país y año.

- d) Realizar un método/script que reciba de parámetro el país y que despliegue toda la información relacionada con el mismo, participaciones, información de medallas, resultados, año de participación, si ha sido sede en alguna ocasión y que años. El formato de salida es a su criterio. Pueden agregar parámetros para filtrar información específica.
